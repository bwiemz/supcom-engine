# Phase 2: In-Game Lua UI Panels (M140–M143) Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire FA's actual Lua HUD files — construction panel, orders panel, unit info, and tooltips — so they boot and function with real engine data.

**Architecture:** Phase 1 established the WorldView, selection bridge, and SimCallback. Phase 2 provides the data-query bindings these panels need. ### Task 1: EntityCategoryGetUnitList on UI state

**Files:**
- Modify: `src/lua/ui_bindings.cpp`

`EntityCategoryGetUnitList` already exists as a real implementation in `sim_bindings.cpp:2483` (registered on `sim_L`). It also exists as a stub in `engine_bindings.cpp:339`. The UI Lua state needs a working version.

- [ ] **Step 1: Register EntityCategoryGetUnitList on ui_L**

The sim_bindings version iterates the BlueprintStore and filters by category. Since the BlueprintStore pointer is shared (stored in both Lua registries via `set_blueprint_store()`), we can register the same function on `ui_L`. However, the sim_bindings version accesses `get_sim(L)` which won't exist on `ui_L`'s registry.

Since `sim_bindings.cpp` already has the full implementation, refactor it into a shared helper that both `sim_L` and `ui_L` can call. Create `src/lua/category_helpers.hpp`:

```cpp
#pragma once

struct lua_State;

namespace osc::blueprints { class BlueprintStore; }

namespace osc::lua {

/// Shared implementation of EntityCategoryGetUnitList.
/// Expects Lua stack: [1] = category table (keys are category names, values are true).
/// Pushes a result table (1-based array of blueprint ID strings) onto the stack.
/// Used by both sim_bindings.cpp and ui_bindings.cpp.
int entity_category_get_unit_list_impl(lua_State* L,
                                        osc::blueprints::BlueprintStore* store);

} // namespace osc::lua
```

Create `src/lua/category_helpers.cpp`:

```cpp
#include "lua/category_helpers.hpp"
#include "blueprints/blueprint_store.hpp"

extern "C" {
#include <lua.h>
#include <lauxlib.h>
}

namespace osc::lua {

int entity_category_get_unit_list_impl(lua_State* L,
                                        osc::blueprints::BlueprintStore* store) {
    lua_newtable(L);
    int result = lua_gettop(L);
    int out_idx = 1;

    if (!store || !lua_istable(L, 1)) return 1;

    auto& all_ids = store->all_blueprint_ids();
    for (const auto& bp_id : all_ids) {
        store->push_lua_table(L, bp_id);
        if (!lua_istable(L, -1)) { lua_pop(L, 1); continue; }

        // Get blueprint's Categories table
        lua_pushstring(L, "Categories");
        lua_rawget(L, -2);
        if (!lua_istable(L, -1)) { lua_pop(L, 2); continue; }
        int bp_cats = lua_gettop(L);

        // Check: every key in the filter (arg 1) must exist in bp Categories
        bool match = true;
        lua_pushnil(L);
        while (lua_next(L, 1) != 0) {
            // key is at -2 (category name string), value at -1 (true)
            lua_pop(L, 1); // pop value, keep key for next iteration
            // Look up this key in bp's Categories table
            lua_pushvalue(L, -1); // copy key
            lua_rawget(L, bp_cats);
            if (lua_isnil(L, -1)) {
                lua_pop(L, 2); // pop nil + key
                match = false;
                break;
            }
            lua_pop(L, 1); // pop the value from bp Categories
        }

        lua_pop(L, 2); // pop bp Categories + blueprint table

        if (match) {
            lua_pushstring(L, bp_id.c_str());
            lua_rawseti(L, result, out_idx++);
        }
    }

    return 1;
}

} // namespace osc::lua
```

Then in `src/lua/ui_bindings.cpp`, the binding is trivial:

```cpp

static int l_ui_EntityCategoryGetUnitList(lua_State* L) {
    auto* store = osc::lua::LuaState::get_blueprint_store(L);
    return osc::lua::entity_category_get_unit_list_impl(L, store);
}
```

And refactor `sim_bindings.cpp`'s existing `EntityCategoryGetUnitList` to call the same shared helper.

FA's `construction.lua` requests blueprint icons via `Display.IconPath` from the blueprint table. These must be loaded asynchronously (Architectural Constraint #4).

- [ ] **Step 1: Add blueprint icon path helper**

The icon path convention in FA is: `/textures/ui/common/icons/units/{bp_id}_icon.dds`

In `src/lua/ui_bindings.cpp`, add a binding that resolves a blueprint's icon texture and returns a texture handle (or triggers async load):

```cpp
/// GetBlueprintIconPath(bpId) → texture path string
/// Used by construction.lua to get the DDS path for build buttons.
static int l_GetBlueprintIconPath(lua_State* L) {
    const char* bp_id = luaL_checkstring(L, 1);
    // FA convention: /textures/ui/common/icons/units/{bp_id}_icon.dds
    // Some blueprints override via Display.IconPath in the blueprint table
    auto* store = osc::lua::LuaState::get_blueprint_store(L);
    if (store) {
        store->push_lua_table(L, bp_id);
        if (lua_istable(L, -1)) {
            lua_pushstring(L, "Display");
            lua_rawget(L, -2);
            if (lua_istable(L, -1)) {
                lua_pushstring(L, "IconPath");
                lua_rawget(L, -2);
                if (lua_type(L, -1) == LUA_TSTRING) {
                    // Custom icon path from blueprint
                    return 1; // leave string on stack
                }
                lua_pop(L, 1);
            }
            lua_pop(L, 1);
        }
        lua_pop(L, 1);
    }
    // Default path
    std::string path = std::string("/textures/ui/common/icons/units/") + bp_id + "_icon.dds";
    lua_pushstring(L, path.c_str());
    return 1;
}
```

- [ ] **Step 2: Ensure TextureCache async path is used for UI icons**

The existing `TextureCache::get()` method already loads asynchronously — it returns `nullptr` while the async load is in progress, and `fallback_descriptor()` provides a 1x1 placeholder. `get_blocking()` is used only for init-time paths. No new method is needed.

The key is that `construction.lua` will request many icons at once when the player first selects an engineer. The Lua side doesn't directly call TextureCache — it sets texture paths on Bitmap controls, which the UIRenderer resolves through TextureCache during `ui_renderer_.update()`.

The existing flow handles this correctly:
1. Lua sets `bitmap:SetTexture(path)` on each build button
2. UIRenderer reads the texture path from each Bitmap control
3. UIRenderer calls `texture_cache_.get(path)` → returns nullptr on first frame (triggers async load)
4. UIRenderer uses `fallback_descriptor()` as placeholder until texture loads
5. Next `flush_uploads()` call completes the upload; subsequent frames show real texture

No code change needed — verify the UIRenderer fallback path handles nullptr from `get()`.

- [ ] **Step 1: Write FactoryQueue header**

Create `src/lua/factory_queue.hpp`:

```cpp
#pragma once

#include "core/types.hpp"
#include <string>
#include <vector>

struct lua_State;

namespace osc::sim {
class SimState;
class Unit;
}

namespace osc::lua {

/// Tracks which factory unit is being displayed in the build queue UI.
/// construction.lua calls SetCurrentFactoryForQueueDisplay to select it.
class FactoryQueueDisplay {
public:
    /// Set the current factory for queue display. Returns the queue as a
    /// Lua array of {id=bpId, count=N, type="default"} tables.
    void set_current(lua_State* L, sim::Unit* factory);

    /// Query queue without changing current factory.
    void peek(lua_State* L, sim::Unit* factory);

    /// Clear the current factory.
    void clear() { current_factory_id_ = 0; }

    /// Remove count items from queue at index.
    void decrease_count(sim::Unit* factory, int index, int count);

    u32 current_factory_id() const { return current_factory_id_; }

private:
    u32 current_factory_id_ = 0;

    /// Push the build queue for a factory onto the Lua stack as a table.
    static void push_queue_table(lua_State* L, sim::Unit* factory);
};

} // namespace osc::lua
```

- [ ] **Step 2: Write FactoryQueue implementation**

Create `src/lua/factory_queue.cpp`:

```cpp
#include "lua/factory_queue.hpp"
#include "sim/unit.hpp"

extern "C" {
#include <lua.h>
#include <lauxlib.h>
}

namespace osc::lua {

void FactoryQueueDisplay::set_current(lua_State* L, sim::Unit* factory) {
    if (!factory) { lua_newtable(L); return; }
    current_factory_id_ = factory->entity_id();
    push_queue_table(L, factory);
}

void FactoryQueueDisplay::peek(lua_State* L, sim::Unit* factory) {
    if (!factory) { lua_newtable(L); return; }
    push_queue_table(L, factory);
}

void FactoryQueueDisplay::decrease_count(sim::Unit* factory, int index, int count) {
    if (!factory) return;
    auto& queue = factory->build_queue();
    if (index >= 1 && index <= static_cast<int>(queue.size())) {
        auto& entry = queue[index - 1]; // 1-based → 0-based
        entry.count -= count;
        if (entry.count <= 0) {
            queue.erase(queue.begin() + (index - 1));
        }
    }
}

void FactoryQueueDisplay::push_queue_table(lua_State* L, sim::Unit* factory) {
    lua_newtable(L);
    if (!factory) return;

    auto& queue = factory->build_queue();
    for (size_t i = 0; i < queue.size(); ++i) {
        lua_newtable(L);

        lua_pushstring(L, "id");
        lua_pushstring(L, queue[i].blueprint_id.c_str());
        lua_rawset(L, -3);

        lua_pushstring(L, "count");
        lua_pushnumber(L, queue[i].count);
        lua_rawset(L, -3);

        lua_pushstring(L, "type");
        lua_pushstring(L, "default");
        lua_rawset(L, -3);

        lua_rawseti(L, -2, static_cast<int>(i + 1)); // 1-based
    }
}

} // namespace osc::lua
```

**Note:** This assumes `Unit` has a `build_queue()` accessor returning a vector of `{blueprint_id, count}` entries. Verify the existing Unit class has this (from the build/construction system implemented in earlier milestones). If not, add a simple `std::vector<BuildQueueEntry>` to Unit.

```cpp
static osc::lua::FactoryQueueDisplay* get_factory_queue(lua_State* L) {
    lua_pushstring(L, "__osc_factory_queue");
    lua_rawget(L, LUA_REGISTRYINDEX);
    auto* fq = static_cast<osc::lua::FactoryQueueDisplay*>(lua_touserdata(L, -1));
    lua_pop(L, 1);
    return fq;
}

/// SetCurrentFactoryForQueueDisplay(factory) → build queue table
static int l_SetCurrentFactoryForQueueDisplay(lua_State* L) {
    auto* fq = get_factory_queue(L);
    auto* unit = check_unit(L, 1);
    if (fq && unit) {
        fq->set_current(L, unit);
    } else {
        lua_newtable(L);
    }
    return 1;
}

/// PeekCurrentFactoryForQueueDisplay(factory) → build queue table
static int l_PeekCurrentFactoryForQueueDisplay(lua_State* L) {
    auto* fq = get_factory_queue(L);
    auto* unit = check_unit(L, 1);
    if (fq && unit) {
        fq->peek(L, unit);
    } else {
        lua_newtable(L);
    }
    return 1;
}

/// ClearCurrentFactoryForQueueDisplay()
static int l_ClearCurrentFactoryForQueueDisplay(lua_State* L) {
    auto* fq = get_factory_queue(L);
    if (fq) fq->clear();
    return 0;
}

/// DecreaseBuildCountInQueue(index, count)
static int l_DecreaseBuildCountInQueue(lua_State* L) {
    auto* fq = get_factory_queue(L);
    auto* sim = get_sim(L);
    if (!fq || !sim) return 0;

    int index = static_cast<int>(luaL_checknumber(L, 1));
    int count = static_cast<int>(luaL_optnumber(L, 2, 1));

    u32 fid = fq->current_factory_id();
    if (fid > 0) {
        auto* entity = sim->entity_registry().get(fid);
        if (entity && entity->is_unit()) {
            fq->decrease_count(static_cast<osc::sim::Unit*>(entity), index, count);
        }
    }
    return 0;
}
```

### Task 6: IssueUnitCommand and IssueCommand

**Files:**
- Modify: `src/lua/ui_bindings.cpp`

FA's `orders.lua` calls `IssueUnitCommand(units, command)` and `IssueCommand(command)` as generic command dispatchers. The engine already has specific `IssueMove()`, `IssueAttack()`, etc. in `sim_bindings.cpp`. The generic versions delegate to these based on the command type.

- [ ] **Step 1: Write IssueUnitCommand binding**

```cpp
/// IssueUnitCommand(units, commandData) — generic command issuance
/// commandData is a table: {CommandType=N, Target={EntityId=N} or Position={x,y,z}, ...}
/// Delegates to the appropriate Issue* function on sim_L via SimCallback.
static int l_IssueUnitCommand(lua_State* L) {
    if (!lua_istable(L, 1) || !lua_istable(L, 2)) return 0;

    // Read command type
    lua_pushstring(L, "CommandType");
    lua_rawget(L, 2);
    int cmd_type = static_cast<int>(lua_tonumber(L, -1));
    lua_pop(L, 1);

    // Build SimCallback table: {Func="UIIssueCommand", Args={units=..., cmd=...}}
    // This serializes across the sim/ui boundary
    lua_pushstring(L, "SimCallback");
    lua_rawget(L, LUA_GLOBALSINDEX);
    if (!lua_isfunction(L, -1)) { lua_pop(L, 1); return 0; }

    lua_newtable(L); // callback table
    lua_pushstring(L, "Func");
    lua_pushstring(L, "UIIssueCommand");
    lua_rawset(L, -3);

    lua_pushstring(L, "Args");
    lua_newtable(L);

    // Copy command type
    lua_pushstring(L, "CommandType");
    lua_pushnumber(L, cmd_type);
    lua_rawset(L, -3);

    // Copy unit entity IDs
    lua_pushstring(L, "Units");
    lua_newtable(L);
    int unit_count = luaL_getn(L, 1);
    for (int i = 1; i <= unit_count; ++i) {
        lua_rawgeti(L, 1, i);
        auto* unit = check_unit(L, -1);
        if (unit) {
            lua_pushnumber(L, unit->entity_id());
            lua_rawseti(L, -3, i);
        }
        lua_pop(L, 1);
    }
    lua_rawset(L, -3);

    // Copy target if present
    lua_pushstring(L, "Target");
    lua_rawget(L, 2);
    if (!lua_isnil(L, -1)) {
        lua_pushstring(L, "Target");
        lua_pushvalue(L, -2);
        lua_rawset(L, -5); // into Args
    }
    lua_pop(L, 1);

    // Copy position if present
    lua_pushstring(L, "Position");
    lua_rawget(L, 2);
    if (!lua_isnil(L, -1)) {
        lua_pushstring(L, "Position");
        lua_pushvalue(L, -2);
        lua_rawset(L, -5); // into Args
    }
    lua_pop(L, 1);

    lua_rawset(L, -3); // set Args on callback table

    // Call SimCallback with the assembled table
    if (lua_pcall(L, 1, 0, 0) != 0) {
        spdlog::warn("IssueUnitCommand SimCallback error: {}", lua_tostring(L, -1));
        lua_pop(L, 1);
    }
    return 0;
}

/// IssueCommand(commandData) — same as IssueUnitCommand but uses current selection
static int l_IssueCommand(lua_State* L) {
    // Get selected units, then delegate to IssueUnitCommand
    lua_pushstring(L, "GetSelectedUnits");
    lua_rawget(L, LUA_GLOBALSINDEX);
    if (lua_isfunction(L, -1)) {
        if (lua_pcall(L, 0, 1, 0) == 0) {
            // Stack: [1]=commandData (original arg), [-1]=selectedUnits
            lua_insert(L, 1); // move selectedUnits to pos 1
            return l_IssueUnitCommand(L);
        }
        lua_pop(L, 1);
    } else {
        lua_pop(L, 1);
    }
    return 0;
}
```

```cpp
static int l_GetRolloverInfo(lua_State* L) {
    auto* sim = get_sim(L);
    if (!sim) { lua_pushnil(L); return 1; }

    // Determine rollover target: hovered unit or first selected unit
    // The UI dispatch stores the hover entity in registry (set by WorldView HitTest)
    lua_pushstring(L, "__osc_hover_entity_id");
    lua_rawget(L, LUA_REGISTRYINDEX);
    u32 hover_id = static_cast<u32>(lua_tonumber(L, -1));
    lua_pop(L, 1);

    osc::sim::Unit* unit = nullptr;
    if (hover_id > 0) {
        auto* entity = sim->entity_registry().get(hover_id);
        if (entity && entity->is_unit())
            unit = static_cast<osc::sim::Unit*>(entity);
    }

    // Fallback to first selected unit — read selected IDs from registry
    // (Phase 1 stores selected entity IDs in __osc_selected_ids registry key)
    if (!unit) {
        lua_pushstring(L, "__osc_selected_ids");
        lua_rawget(L, LUA_REGISTRYINDEX);
        if (lua_istable(L, -1)) {
            lua_rawgeti(L, -1, 1); // first selected
            u32 first_id = static_cast<u32>(lua_tonumber(L, -1));
            lua_pop(L, 1);
            if (first_id > 0) {
                auto* entity = sim->entity_registry().get(first_id);
                if (entity && entity->is_unit())
                    unit = static_cast<osc::sim::Unit*>(entity);
            }
        }
        lua_pop(L, 1);
    }

    if (!unit) { lua_pushnil(L); return 1; }

    lua_newtable(L);
    auto set_str = [&](const char* k, const char* v) {
        lua_pushstring(L, k);
        lua_pushstring(L, v);
        lua_rawset(L, -3);
    };
    auto set_num = [&](const char* k, f64 v) {
        lua_pushstring(L, k);
        lua_pushnumber(L, v);
        lua_rawset(L, -3);
    };
    auto set_bool = [&](const char* k, bool v) {
        lua_pushstring(L, k);
        lua_pushboolean(L, v ? 1 : 0);
        lua_rawset(L, -3);
    };

    set_str("blueprintId", unit->blueprint_id().c_str());
    set_num("entityId", unit->entity_id());
    set_num("health", unit->health());
    set_num("maxHealth", unit->max_health());
    set_num("kills", unit->kills());
    set_num("armyIndex", unit->army());
    set_num("workProgress", unit->work_progress());

    // Shield ratio

    if (unit->shield() && unit->shield()->max_health() > 0) {
        shield_ratio = unit->shield()->health() / unit->shield()->max_health();
    }
    set_num("shieldRatio", shield_ratio);

    // Fuel ratio (0-1, 1.0 if no fuel system)
    set_num("fuelRatio", 1.0);

    auto& econ = unit->economy();
    set_num("massProduced", econ.production_mass);

    set_num("tacticalSiloMaxStorageCount", unit->tactical_silo_max());

    set_num("nukeSiloMaxStorageCount", unit->nuke_silo_max());

    set_num("nukeSiloBuildCount", 0);

    // userUnit — push unit Lua table (with _c_object + metatable)
    // Uses the same pattern as check_unit() but in reverse:
    // create table, set _c_object lightuserdata, set __osc_unit_mt metatable
    lua_pushstring(L, "userUnit");
    lua_newtable(L);
    lua_pushstring(L, "_c_object");
    lua_pushlightuserdata(L, unit);
    lua_rawset(L, -3);
    // Apply cached unit metatable
    lua_pushstring(L, "__osc_unit_mt");
    lua_rawget(L, LUA_REGISTRYINDEX);
    if (lua_istable(L, -1)) {
        lua_setmetatable(L, -2);
    } else {
        lua_pop(L, 1);
    }
    lua_rawset(L, -3);
```
